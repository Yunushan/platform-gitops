# Release Notes

## v0.1.0

Initial project template with:

- 0BSD license.
- 3-node RKE2 default architecture.
- Forgejo + Woodpecker CI + Argo CD HA default stack.
- Harbor, CloudNativePG, Longhorn, MetalLB, ingress-nginx, Prometheus/Grafana, Loki, Velero.
- Alternatives for Gitea, GitLab CE, GitLab Runner, Rook/Ceph, Traefik, HAProxy/Keepalived.
- GitHub, GitLab, Gitea, Forgejo, and Woodpecker CI validation files.
- 20 global-language starter docs.
- 20 programming-language starter scaffolds.
- Secret and private-data protection checks.
